# Environment Variables

This project uses environment variables to configure different behaviors for development and production.

## Files

- **`.env`** - Development environment (local)
- **`.env.production`** - Production environment (GitHub Pages)
- **`.env.example`** - Template for new developers

## Configuration

### Development (Local)

```bash
# .env
EXPO_PUBLIC_BASE_URL=
```

Empty `BASE_URL` means workers load from root: `/kokoro-worker.js`

### Production (GitHub Pages)

```bash
# .env.production
EXPO_PUBLIC_BASE_URL=/narra
```

With `/narra` base path, workers load from: `/narra/kokoro-worker.js`

## How it works

1. Expo automatically loads `.env` for development
2. Expo automatically loads `.env.production` when running `expo export` with `NODE_ENV=production`
3. The `EXPO_PUBLIC_*` prefix makes variables available in the client code
4. The speech service uses `process.env.EXPO_PUBLIC_BASE_URL` to construct worker URLs

## Setup for new developers

```bash
cp .env.example .env
# Edit .env with your local configuration
```
